# T-Tracker

تطبيق متابعة مهام أندرويد مع أربعة ودجت للشاشة الرئيسية.

| | |
| --- | --- |
| **الاسم** | T-Tracker |
| **الحزمة** | `com.ajami.sos` |
| **الودجت** | مهام · ميمو · نتيجة · تقويم |
| **الوضع** | داكن (HUD) + فاتح مريح |

## المزايا

- **خلفية منحوتة** — صورة الأرض ليلاً مدمجة مع ألوان التطبيق (شفافة فوقها البطاقات).
- **تقويم داخلي** — شبكة شهر بنقاط المهام والميمو، بلا حزم خارجية.
- **مهام متكررة بنافذة** — الخطة المسبقة 15 نوفمبر → 13 ديسمبر تظهر في الودجت والتقويم.
- **ودجت التقويم** — تقويم شهري كامل على الشاشة الرئيسية.
- **إعدادات الودجت** — حجم الخط والشفافية من داخل التطبيق.
- **وضع فاتح** — زر في الشريط العلوي.
- **زر + صغير** بدل زر المهمة العريض.
- **لا شاشة ساترة** — التطبيق لا يخفي نفسه عند الخروج.

## النشر

الـ APK يُبنى تلقائياً على GitHub Actions:

**Actions → Build APK → latest run → Artifacts → `T-Tracker-apk`**

## أداء

- الصورة تُفكّ بحدود عرض الشاشة (`ResizeImage`).
- قوائم الشاشة الرئيسية lazy عبر `CustomScrollView` + `SliverChildBuilderDelegate`.
- خريطة «يوم → مهام» تُبنى مرة واحدة لكل شهر، لا لكل خلية.
- المطر الرقمي اختياري ومحسوب مسبقاً.
